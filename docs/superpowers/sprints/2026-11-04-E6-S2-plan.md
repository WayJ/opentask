# E6-S2 — Issue.cycle_id + 列表/看板筛选 + 指派 + ⌘K Cycles

**本 Sprint 范围**：`issues.cycle_id` (+ optional `estimate_points`)；Issue create/update/list 接受/返回/过滤 `cycle_id`；跨租户 Cycle 校验；FE 列表/看板 Cycle 筛选与指派；⌘K `kind=cycle`。  
**明确不做（→ S3）**：complete/rollover、capacity hint、generate-upcoming 打磨、Jira sprint 接通。

**汇报**：Sprint 中间不单独找 Yuri/Way 验收；整 Epic（S1–S3）本地收口后一次性回执。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | `cycle_id` FK → `cycles.id` ON DELETE SET NULL | Epic D3 | CASCADE 删 Issue |
| D2 | 可选 `estimate_points` Numeric(8,2)；保留 `estimated_hours` | Epic D8 | 替换工时 |
| D3 | 同 workspace 校验：指派 Cycle 必须属 Issue 所在 workspace | 租户安全 | 仅 FK 无服务层校验 |
| D4 | list query `cycle_id`；`__none__` = 无 Cycle | FE「无 Cycle」选项 | 仅客户端滤 |
| D5 | PATCH Issue 写 `cycle_id`（兼专用 PUT 可选） | 与 assignee 模式一致 | 强制新端点 |
| D6 | ⌘K `kind=cycle`：有 query 搜 name → 跳 `/issue/list?cycle_id=` | 设计 §6.3 | 仅跳设置页 |
| D7 | 中途不 ping Way/Yuri | Epic D11 | 逐 Sprint 验收 |
