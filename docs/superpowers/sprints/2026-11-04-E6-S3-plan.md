## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | complete 仅 active→completed；须先 complete 才能 activate 下一 | 设计 §5 / S1 activate 已拒双 active | complete 时自动 activate |
| D2 | 未完成 = status ∉ {resolved, closed}；完成留原 Cycle | Epic D5 | rejected 算完成 |
| D3 | into_next：无下一 upcoming → 自动 generate-upcoming 再滚 | 设计 §5.1 锁定 | 强制 leave_unassigned |
| D4 | leave_unassigned：未完成 cycle_id=NULL | Epic D5 | 删 Issue |
| D5 | capacity：近 N completed 的「仍挂该 Cycle 且 resolved/closed」均值；无历史 → member_count | 设计 §5.2 | 复杂 velocity 图 |
| D6 | generate-upcoming：starts=max(last ends_at, now)；ends=starts+duration | 设计 §5 | 固定日历对齐 |
| D7 | 路由静态路径 `/capacity-hint` `/generate-upcoming` 注册在 `/{cycle_id}` 之前 | FastAPI 匹配序 | 嵌套 router |
| D8 | 中途不 ping；Epic status=local-complete；merged-commit null；无 push | 指派 | 开 PR |
