# E6-S1 — Cycle CRUD API + Alembic + Cycles 设置列表 UI

本文件即 sprint 台账。分支 `sprint/E6-S1`（基于 `sprint/E5-S3` tip `da13c86`）；worktree `/workspace/opentask-worktrees/E6-S1`。本轮不推远程。

**本 Sprint 范围**：`cycles` 表 + Workspace Cycles 设置列 + `/api/cycles` CRUD + 设置页列表/启用/创建 upcoming。  
**明确不做（→ S2/S3）**：`Issue.cycle_id`、列表筛选、⌘K Cycles、complete/rollover、capacity hint 精修。

**汇报**：Sprint 中间不单独找 Yuri/Way 验收；整 Epic（S1–S3）本地收口后一次性回执。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | Workspace 级 `cycles` 新表；非 Team | PRD / Epic D1 | 仿 Team 多日历 |
| D2 | S1 **不**加 `issues.cycle_id` | S1 可独立验 CRUD；归属归 S2 | S1 塞满 FK+UI |
| D3 | Workspace 列：`cycles_enabled` / `cycle_duration_days` / `cycle_rollover_policy` / `cycle_capacity_lookback` | 设置页与空状态需要真相源 | 仅 JSON blob 无列 |
| D4 | API `/api/cycles`；强制 `X-Workspace-Id`；写 member+；设置开关 owner | 与 E3/E4 一致 | 无头全局 Cycle |
| D5 | S1 允许创建 `upcoming`；`activate` 可先做最小版或留 S3（**推荐 S1 提供 activate，complete 留 S3**） | 设置页可演示「当前冲刺」 | S1 只读列表无状态迁移 |
| D6 | 删除仅 `upcoming` | 防误删 active 历史 | 任意状态可删 |
| D7 | FE 路由新建 Cycles 设置页（建议 `/workspace/cycles`） | 现无 Workspace Settings 壳 | 塞进 theme-drawer |
