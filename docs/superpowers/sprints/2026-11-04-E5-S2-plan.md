# E5-S2 — 命令面板实体搜索（Issues / Projects / Saved Views）

本文件即 sprint 台账。分支 `sprint/E5-S2`（基于 `sprint/E5-S1` tip `3075de2`）；worktree `/workspace/opentask-worktrees/E5-S2`。本轮不推远程。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | 实体结果进同一 palette：Actions/Menus + Issues + Projects + Views | 设计 / Linear 手感 | 独立搜索页 |
| D2 | Issue 标题走 `GET /api/issues?search=`；code 形再打 `getIssue(code,{byCode:true})` | 后端已有；FE 补 byCode | 只靠 search ilike |
| D3 | Projects / Saved Views：list + 客户端 name `includes` 过滤 | 现 API 无 search | 新后端端点 |
| D4 | Saved View 选中 → `router.push({ path:'/issue/list', query:{ view:id }})`；列表消费 query 并复用 apply 纯函数 | 面板不在 list 内也能 apply | 仅 pinia 无 URL |
| D5 | 查询防抖 300ms；空 query 只显示 Actions（不做 recent） | 设计 YAGNI | recent 持久化 |
| D6 | 零新依赖；继续 vitest + lint/build + pytest 回归 | 与 S1 门禁一致 | cmdk / fuse |
