# E8-S1 — Milestones + issue.milestone_id + 项目日期 + 项目 UI

本文件即 sprint 台账（**Phase 1 stub**）。分支 `sprint/E8-S1`（基于 `sprint/E7-S3` tip `68740f7`）；worktree `/workspace/opentask-worktrees/E8-S1`。本轮 **仅文档**；不写产品实现；不推远程。

**本 Sprint 范围（实现阶段）**：`milestones` 表 + `issues.milestone_id` + `projects.starts_at`/`target_date` + nested milestones API + 项目详情里程碑/日期 UI + Issue 详情挂载里程碑。

**汇报**：Sprint 中间不单独找 Yuri/Way 验收；整 Epic（S1–S3）本地收口后一次性回执。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | 嵌套 API `/api/projects/{id}/milestones` | 与 repos 一致；租户经项目 | 仅顶层 `/api/milestones` |
| D2 | S1 **同迁** `issues.milestone_id` + 项目日期 | Timeline/归属下一 Sprint 需要数据；S1 可独立验挂载 | 日期推迟到 S2 |
| D3 | Alembic `down_revision = d4e5f6a7b8c0` | E7 tip head | 错接更旧 revision |
| D4 | milestone.status 默认 `planned`；可选 `done` | Roadmap Q5 | 无状态列 |
| D5 | 挂载校验：milestone.project_id == issue.project_id | project_id 无 FK | 信任客户端 |
| D6 | FE 继续 `project-detail?id=`；不强制改 path param | 现状路由 | 本 Sprint 大改 elegant 路径 |
| D7 | Phase 1 不写 `plans/…` 细 TDD 文；实现开工前再补 | 指派「S1 stub」 | 本提交塞满实现任务勾选 |
