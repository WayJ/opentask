# E4-S3 — 一等公民子 Issue（parent_issue_id）

本文件即 sprint 台账。分支 `sprint/E4-S3`（基于 `sprint/E4-S2` tip `1e79a91`）；worktree `/workspace/opentask-worktrees/E4-S3`。本轮不推远程。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | Issue 增加可空 `parent_issue_id` FK → `issues.id` | ADR D6；一等公民嵌套 | IssueRelation parent/child —— 拒绝 |
| D2 | 服务层强制同 `workspace_id`；拒自指；拒环（祖先链含自身） | 租户隔离 + 数据完整 | 仅靠 DB CHECK —— 不够表达环 |
| D3 | list/get 恒返回 `parent_issue_id`；get 另带 `children` 摘要；另提供 `GET /{id}/children` | 对现有客户端 additive；列表避免 N+1 | list 全量嵌套树 —— 过重 |
| D4 | 列表嵌套：**客户端**在当前筛选结果内做 depth-1 缩进；父不在结果集则子作顶层 | 与 S2 客户端呈现一致；简单可测 | 服务端树分页 —— 延后 |
| D5 | 清空 parent：PATCH/PUT `parent_issue_id: null` | Linear 可拆分父子 | 禁止清空 —— 拒绝 |
