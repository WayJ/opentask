# S2 — 门禁验证：死引用修复 + D11 PostgreSQL 切换 + pytest/lint/build 全绿

本文件即 sprint 台账。一个 sprint = 一个 worktree/分支（`sprint/E1-S2`，基于 main@e2e6ade）。状态流转属主：start（active）、accept（acceptance）、complete（merged）、roadmap（closed），不得手工翻转。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | S2 载体基于 main（e2e6ade）而非叠加 S1 分支；S1 在 S2 落地后经 sync 合并 + 重验收完成收尾 | S2 合并若叠加携带 S1 树外变更，会破坏 S1 land 的候选树校验语义；S1 场景在含 S2 修复的树上重跑成本低（CLI 快测 + 扫描） | 叠加分支直接合并 —— 拒绝：S1 的 accepted tree 与落点树不等，land 校验语义受污染 |
| D2 | PostgreSQL 供库用 Docker 容器（postgres:16），端口/库名/用户与 test.yaml 对齐；容器编排写入 backend/README.md | 本机无原生 psql/mysqld（实测）；Docker 29.9.2 可用（实测 `docker ps` OK）；D11 要求 dev/test/prod 统一 PG | 本机安装 PostgreSQL 服务 —— 拒绝：系统级侵入且不可移植 |
| D3 | 前端依赖用 pnpm 安装（workspace 协议），门禁命令保持 verbatim `npm run lint && npm run build` | npm ci 实测 EUNSUPPORTEDPROTOCOL "workspace:*"（soybean-admin 上游 pnpm 项目）；npm run 仅作 script runner 从 node_modules/.bin 解析，与安装器无关 | 改门禁命令为 pnpm run —— 拒绝：门禁命令属宿主配置，不得为迁就环境改写 |
| D4 | backend/README.md 的 PG 文档同步与 config/*.yaml 变更必须在同一提交落盘 | doc_sync_map 行 `backend/config/*.yaml → backend/README.md`；complete 阶段 1 的欠账检查要求同提交 | 分开提交 —— 拒绝：构成 doc-sync 欠账阻断合并 |

## Stories & Tasks

### Wave 1 — 数据库与后端门禁

- [ ] D11 PG 切换：`backend/opentask/config.py` 的 MYSQL_* 环境变量映射 → PG 等价（POSTGRES_*/DATABASE_*），mysql_* 属性族 → postgres_*；`backend/config/*.yaml` `database.mysql` 段 → `database.postgres`
- [ ] conftest/数据库连接层：`TEST_DATABASE_URL` 由 `mysql+aiomysql` → `postgresql+asyncpg`（驱动已在 pyproject）
- [ ] Docker PG 容器就绪：postgres:16、端口/库/用户与 test.yaml 一致、named volume、启动命令写入 backend/README.md（与 yaml 变更同提交）
- [ ] TD1 死引用清除：`api/git/router.py` 与 `services/git_service.py` 的 `opentask.services.file_storage`、`services/conversation.py` 的 `agent_v3.integration`、`tests/agent_task/*` 的 agent_task 模块引用（二选一：补模块或删引用，按 TD1 还款标准）
- [ ] backend pytest 全绿：`cd backend && uv run pytest tests/ -v` 0 failed（当前基线 78F/196P/178E：无 DB + 死引用 + 存量失败）
- [ ] 导入图零缺失维持：`uv run python -c "import opentask.api"`

### Wave 2 — 前端门禁

- [ ] `cd frontend && pnpm install`（node_modules 就绪）
- [ ] `cd frontend && npm run lint` 0 error
- [ ] `cd frontend && npm run build` 成功产出 dist
