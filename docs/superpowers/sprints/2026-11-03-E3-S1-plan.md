# E3-S1 — 开放注册 + Workspace 租户边界

本文件即 sprint 台账。分支 `sprint/E3-S1`；worktree `/workspace/opentask-worktrees/E3-S1`。本轮不推远程（SSH/GitHub 待 Way 配置）。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | `POST /api/auth/register` 体字段：`userName` + `password`（+ 可选 `name`）；密码经 `_plain_password` | 与 login Body 别名一致，前端改动最小 | 手机+验证码 —— 拒绝：未接线 |
| D2 | 注册同事务：建 User（role=viewer, status=1）+ 默认 Workspace + owner Membership + 签发 token 对 | 注册即可用 | 仅建用户、强制二次创建工作区 —— 拒绝：空租户体验差 |
| D3 | 上下文头 `X-Workspace-Id`；依赖 `get_current_workspace` 校验成员资格 | 见 epic D4 | query `workspace_id` —— 可作后备但不做主路径 |
| D4 | 迁移：建 `workspaces` / `workspace_members`；`projects.workspace_id` / `issues.workspace_id`；插入系统 `Default Workspace` 并 backfill；Project 唯一约束改 `(workspace_id, name)` | 见 epic D5/D6 | 应用层软隔离无 FK —— 拒绝：无法防漏 |
| D5 | 成员 API：list / add / remove；仅 owner 可 add/remove 与改工作区名 | 最小授权 | 复用全局 RBAC 权限码 —— 可后补，S1 先角色列 |
| D6 | 前端：重写 register.vue 为用户名+密码；恢复 login index 注册入口；顶栏简易 Workspace 切换（NSelect） | DESIGN.md / Naive | 完整设置页 —— 留给后续 |
