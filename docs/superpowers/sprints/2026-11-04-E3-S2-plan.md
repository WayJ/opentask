# E3-S2 — Issue 看板 + 列表双视图

本文件即 sprint 台账。分支 `sprint/E3-S2`（基于 `sprint/E3-S1` tip）；worktree `/workspace/opentask-worktrees/E3-S2`。本轮不推远程。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | 双视图共用 `/issue/list` 页：工具栏切换 list ↔ board，不新增独立路由 | 保持同一数据源与 Workspace 头；减少路由漂移 | 独立 `/issue/board` —— 拒绝：易分叉筛选状态 |
| D2 | 看板列 = 既有 `IssueStatus` 六态（open / in_progress / feedback / resolved / closed / rejected）；不改枚举名 | Epic ADR D8 | 合并列或自定义看板列 —— 拒绝：超出 S2 |
| D3 | 拖拽落盘：`POST /api/issues/board/move` 原子写 `status` + `position`；同列重排可附带 `ordered_ids` 批量写 position | 看板一次落库；复用 timeline 状态变更逻辑 | 仅两次独立 PUT —— 可作后备，主路径用 board/move |
| D4 | 列表 `sort_by=position` 白名单放行；NULL position 排后 | 看板与列表同源排序 | 另开 board-only 列表接口 —— 拒绝：违反「同数据源」 |
| D5 | 前端用已有 `vue-draggable-plus`；卡片展示 title / assignee / issue_code | DESIGN.md / Naive；零新依赖 | Element 看板 —— 拒绝：项目已弃 Element |
| D6 | `X-Workspace-Id` 下 move 校验 issue.workspace_id 一致；跨区 403/404 | 延续 S1 租户边界 | 无头可改任意 id —— 拒绝：泄漏面 |
