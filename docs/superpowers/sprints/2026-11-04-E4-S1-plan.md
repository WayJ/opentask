# E4-S1 — 个人 Saved Views（收藏筛选与排序）

本文件即 sprint 台账。分支 `sprint/E4-S1`（基于 `sprint/E3-S3` tip `61d2f40`）；worktree `/workspace/opentask-worktrees/E4-S1`。本轮不推远程。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | 仅个人 `owner_user_id`；不做工作区共享 | Way 拍板；Linear Custom Views MVP | 共享视图 —— 另开 Epic |
| D2 | 新表 `issue_saved_views`，不复用 IssueCollection | Collection = issue_id 袋；Views = 配置 | 扩展 Collection —— 语义错位 |
| D3 | API `/api/saved-views` + 强制 X-Workspace-Id | 与 E3 租户头一致 | 嵌套 `/workspaces/{id}/views` —— 多余 |
| D4 | filter_json 对齐 ParsedQuery / IssueQueryParams | 复用智能搜索与列表筛选 | 另发明查询 DSL —— 拒绝 |
| D5 | 前端改 Issue 列表工具栏；Naive / DESIGN.md | 现有入口最近 | 独立 Views 管理页 —— S1 过重 |
| D6 | 测试库 create_all + alembic 迁移 | 延续 Inbox 模式 | 仅 raw SQL —— 不必要 |
