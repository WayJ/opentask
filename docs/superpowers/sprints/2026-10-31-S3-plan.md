# S3 — 公开发布：openapi 重生成 + 凭据终扫 + 推送 GitHub + 远端核对

本文件即 sprint 台账。一个 sprint = 一个 worktree/分支（`sprint/E1-S3`，Orca 原生工作区，基于 main@62eb6ee）。frontmatter worktree 为分支名。本 sprint 由协调者亲自执行（轻量发布动作，无 worker 派发）。

## Decisions (D-x)

| id | decision | rationale | rejected alternatives |
|---|---|---|---|
| D1 | TD5 处置取「重新生成」：推送前用 FastAPI 导出覆盖 backend/openapi.json / openapi_current.json | 消除仓内最后一处 vibeking 字符串（DoD 扫描从「允许命中」升为「零命中」）；后端可运行，导出即得 | 按现状带历史 —— 拒绝：公开仓库携旧品牌串不必要；.gitignore 化 —— 拒绝：spec 应随代码发布 |
| D2 | 推送命令由用户在其终端执行（`!` 前缀交互式） | 本机 git 凭据管理器在非交互 shell 无法弹窗（supervibe push 已实证）；推送是外向不可逆动作，交互终端完成凭据与确认双重目的 | 协调者盲推 —— 拒绝：凭据不可得且不符确认纪律 |
| D3 | 推送前后各跑一次凭据扫描 | 推送前拦截 + 推送后核验远端状态，双保险 | 单次扫描 —— 拒绝：DoD 明列推送后核对 |

## Stories & Tasks

### Wave 1 — 发布

- [ ] 重新生成 backend/openapi.json 与 openapi_current.json（FastAPI app.openapi() 导出）
- [ ] 全仓凭据模式终扫（AKIA/ghp_/sk-/私钥/JWT）+ vibeking 终扫（目标：零命中）
- [ ] git push origin main（用户终端执行）
- [ ] git ls-remote origin 核对 + 远端文件清单抽查（无 local.yaml/.env.prod.local 等）

## Definition of Done

- [ ] `git log` 显示首次提交，且 `git ls-files` 中不含 `config/local.yaml`、`.env.prod.local`、`extensions/chatapp/.env.prod` 等含真实凭据文件
- [ ] 全仓库扫描 `vibeking|Vibe King|VIBE_KING|vibe-king|vibe_king` 仅命中 `backend/openapi*.json`（自动生成产物）
- [ ] 全仓库扫描高危密钥模式（AKIA/sk-/ghp_/私钥/JWT）零命中
- [ ] `cd backend && uv run pytest tests/ -v` 通过
- [ ] `cd frontend && npm run lint && npm run build` 通过
- [ ] `cd agent-harness/opentask-cli && pip install -e . && opentask --version` 输出正确版本号
- [ ] 后端与 CLI 的导入图静态校验零缺失（改名引入的）
- [ ] 推送后 `git ls-remote origin` 显示远端分支与本地一致
