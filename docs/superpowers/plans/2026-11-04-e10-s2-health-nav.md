## Health formula

Linked projects' `health_status` ∈ {on_track, at_risk, off_track, null}:

```
severity: off_track=3 > at_risk=2 > on_track=1 > unknown/null=0
overall = max severity among linked; null if projectCount==0 OR all unknown
counts: { onTrack, atRisk, offTrack, unknown }
projectCount: len(projectIds)
```

Response camelCase:

```json
"healthSummary": {
  "overall": "at_risk",
  "counts": { "onTrack": 1, "atRisk": 1, "offTrack": 0, "unknown": 0 },
  "projectCount": 2
}
```

Detail may also include `projects: [{ id, name, healthStatus }]` for UI.
