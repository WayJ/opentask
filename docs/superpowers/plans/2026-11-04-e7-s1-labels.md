3. For each Tag: find linked Issues via `issue_tags` → `issues.workspace_id`

   - Else if multiple WS → earliest Issue's WS (min created_at); on name conflict in that WS append `-migrated` / `-migrated2`…
   - Else (orphan) → first Workspace by `created_at` (or any); same conflict rule
