# E11-S3 Status hooks + polish + Epic local-complete Implementation Plan

> **For agentic workers:** Inline execution (no questions). Checkbox steps for tracking.

**Goal:** Optional Workspace git status hooks (default off); webhook applies Issue status only when enabled; FE toggle; CLI/Agent contract docs; Epic DoD + acceptance. No live GitHub App. No push.

**Architecture:** Alembic adds `git_status_hooks_enabled` (+ optional target status columns) on `workspaces`; hook runs after webhook `upsert_github_pr`; FE Workspace settings Toggle; CodingWorker.md documents same HTTP as CLI/FE.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, pytest/httpx, Vue3+Naive.

## Global Constraints

- Hooks **default off**
- When on: PR open/draft → `in_progress` only if Issue currently `open`; merged → `resolved` if not `closed`/`rejected`; closed-unmerged → **no** Issue change
- Never `requirement_repos`/PGE; live GitHub App not DoD
- Alembic: new rev `e5f6a7b8c9d0` ← `d4e5f6a7b8c9`
