> **For agentic workers:** REQUIRED 本会话 inline 执行；**TDD**；频繁 commit；**禁止 push/PR**；**不自开 E43**。

**Goal:** WS 可配置 time-in-status SLA 策略；Issue 进 start 启钟、进 stop/关闭类满足；外部 `POST /api/sla/run-due` 判违约 + Inbox/可选 webhook；FE 设置+徽标；CLI **1.26.0**。

**Architecture:** 新表 `sla_policies` + `issue_sla_clocks`；`IssueService._sync_sla_clocks` 挂 create/update 同事务；`SlaService` 管 CRUD + run-due（对齐 E35/E38/E39 外部 tick）；复用 E27 prefs / E29 webhooks / E30 email。

**Tech Stack:** FastAPI + SQLAlchemy + Alembic；Vue3/Naive；Click CLI；pytest/vitest。

## Global Constraints
- 本地 tip；禁止 push/PR；不自开 E43；中文 docs；CLI **1.26.0**
- metric 仅 `time_in_status`；target_minutes 1…10080；日历分钟 UTC naive
- stop 非空→严格按 stop；空→`{resolved,closed,rejected}`（D3）
- 多策略并发；每 (issue,policy) 至多一条 running（D4）
- `enabled=false`：tick 不 breach（D5）；running 保留
- 外部 run-due only；无进程内 cron（D6）
- create 也启钟；bulk YAGNI（D8）
- 非目标见 design §4
